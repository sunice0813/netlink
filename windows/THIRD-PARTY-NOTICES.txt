NetLink for Windows — third-party components
=============================================

NetLink itself is released under the MIT License (LICENSE.txt).

The installer also ships the official OpenConnect Windows build, unmodified, in the
"openconnect" folder. It was taken from the OpenConnect project's GitLab CI build of
tag v9.12 (job 4319289314, openconnect-installer-MinGW64-GnuTLS.exe,
sha256 bb7fe698c757e003af74dcfbf1ec30f64432fa4bb0e1a27e28b8a9e86f765f8e).
NetLink runs openconnect.exe as a separate program and does not link to it.

Source code for these components is available from their upstream projects listed
below; the exact OpenConnect source is the v9.12 tag at
https://gitlab.com/openconnect/openconnect/-/tree/v9.12
